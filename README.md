# Chameleon project page

This repository contains a static GitHub Pages site for **Chameleon: Benchmarking Detection and Backtracking on Commercial-Grade AI-Generated Videos**.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.

The site is buildless: GitHub Pages serves `index.html` directly. The PDF is `icmr26_305.pdf`; the full video dataset remains hosted on [Hugging Face](https://huggingface.co/datasets/viviwang/Chameleon).
